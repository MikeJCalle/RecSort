# REecSort

**Recursive sort expression compiler.** Write a four-line `.nst` declaration, get a clean, null-safe, self-contained Python sort function — no runtime dependency, no boilerplate.

```
sort orders
  by status asc, date desc
  then items
    by price asc
  nulls last
```

Compiles to a ready-to-use `sort_orders(data)` Python function that correctly handles every nesting level, null value, and sort direction.

---

## The problem

Sorting a flat list in Python is one line. Sorting nested data — a list of orders each containing a list of items, with mixed-direction keys and nullable fields — means writing the same fragile lambda tower from scratch every single time:

```python
# what you'd have to write manually
def sort_orders(orders):
    for o in orders:
        o["items"] = sorted(
            o.get("items") or [],
            key=lambda x: (x.get("price") is None, x.get("price"))
        )
    return sorted(orders, key=lambda o: (
        o.get("status") is None, o.get("status"),
        -(o.get("date") or 0)
    ))
```

RecSort generates that code from a four-line declaration — and catches errors like missing keys and ambiguous directions *before* any code runs.

## Quick start

**1. Write a `.nst` file**

```
# orders.nst
sort orders
  by status asc, date desc
  then items
    by price asc
  nulls last
```

**2. Compile it**

```bash
recsort orders.nst
# ✓ orders.nst → orders.py  (function: sort_orders)
```

**3. Use the generated function**

```python
from orders import sort_orders

result = sort_orders(my_data)
```

That's it. The generated `orders.py` has zero imports and no dependency on NestSort at runtime.

## `.nst` syntax

```
sort <n>
  by <key> asc|desc [, <key> asc|desc ...]
  then <list-key>
    by <subkey> asc|desc
  nulls first|last
```

| Keyword | Description |
|---------|-------------|
| `sort <n>` | Names the block and the generated function (`sort_<n>`) |
| `by <key> asc\|desc` | Sort key with direction. Chain multiple with commas. |
| `then <list-key>` | Sub-sort: for each item, sort the list at `item["list-key"]` |
| `nulls first\|last` | Where `None` values land. Default: `last` |

**Dot notation** is supported for nested keys: `by customer.name asc`

## What gets generated

The emitted Python is readable, commented, and self-contained:

```python
class _Desc:
    """Wraps a value so it sorts descending via comparison inversion."""
    ...

# sort orders: status asc, date desc  |  nulls last
def sort_orders(data):
    """Sort 'orders' — generated by NestSort v0.1."""
    # sub-sort 'items' within each item → price asc
    for _ci in data:
        _ci["items"] = sorted(
            _ci["items"],
            key=lambda _si: (True if _si.get('price') is None else False,
                             _si.get('price') if _si.get('price') is not None else '')
        )
    # by: status asc, date desc  (nulls last)
    data = sorted(
        data,
        key=lambda _x: (
            (True if _x.get('status') is None else False, _x.get('status') or ''),
            (True if _x.get('date') is None else False, _Desc(_x.get('date')) or '')
        )
    )
    return data
```
